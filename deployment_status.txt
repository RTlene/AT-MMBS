## 部署指令

### 本地Docker部署
```bash
# 1. 克隆仓库
git clone https://github.com/RTlene/AT-MMBS.git
cd AT-MMBS

# 2. 切换到开发分支
git checkout 开发中

# 3. 执行部署
./deploy.sh
```

### 手动部署
```bash
# 1. 配置环境
cp .env.example .env
vim .env

# 2. 启动服务
docker-compose up -d

# 3. 查看日志
docker-compose logs -f
```

### 测试部署
```bash
# 运行部署测试
./test-deployment.sh
```
