🎯 RESTful API功能测试页面

这个页面用于测试RESTful API是否正常工作

测试操作：

用户列表：

点击"测试获取用户列表"按钮来加载数据

调试日志：

日志将在这里显示...

测试说明：

  1. 点击"测试获取用户列表"按钮测试GET /api/users
  2. 点击"测试添加用户"按钮测试POST /api/users
  3. 点击"测试获取单个用户"按钮测试GET /api/users/{id}
  4. 点击"测试更新用户"按钮测试PUT /api/users/{id}
  5. 点击"测试删除用户"按钮测试DELETE /api/users/{id}
  6. 观察用户列表是否正确显示和更新
  7. 查看调试日志了解API响应详情
